# Manual de Usuario — Sistema Correos IA

## 1. Acceso
1. Abrir `http://localhost/sistema-correos-ia/`.
2. Ingresar usuario y contraseña.
3. El sistema dirige al Dashboard.

## 2. Dashboard
Presenta indicadores, distribución de prioridades y categorías, confianza de IA, concordancia IA/revisión humana y evolución temporal. Los filtros dependen de los permisos y cuentas autorizadas.

## 3. Gestión de Gmail
Desde la opción correspondiente, el usuario autorizado puede conectar cuentas Google y ejecutar la sincronización. La sincronización importa mensajes según la configuración del sistema y evita duplicados.

## 4. Correos y clasificación
El módulo permite buscar, filtrar y consultar correos. Un usuario con `clasificar_correos` puede ejecutar la clasificación de un correo o de pendientes.

## 5. Revisión humana
Un usuario autorizado consulta la clasificación de IA y establece la prioridad final. La primera revisión se registra; una revisión existente se modifica en lugar de crear un duplicado.

## 6. Usuarios
El administrador puede crear, editar y activar/desactivar usuarios según sus permisos.

## 7. Cierre de sesión
Utilizar siempre la opción Cerrar sesión.
