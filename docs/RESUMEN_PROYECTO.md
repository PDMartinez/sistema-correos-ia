# Resumen del sistema

El sistema integra cuentas Gmail autorizadas, importa y administra correos, aplica clasificación automática mediante IA según prioridad y categoría, permite revisión humana y presenta estadísticas para seguimiento.

## Módulos implementados
1. Autenticación y autorización.
2. Usuarios.
3. Gmail/OAuth y sincronización.
4. Gestión de correos.
5. Clasificación IA.
6. Revisión humana.
7. Dashboard y estadísticas.
8. Seguridad.
9. Pruebas.
10. Documentación.

## Nota de evaluación
La concordancia IA/humano debe interpretarse como una métrica de comparación con la revisión humana definida para el proyecto, no como una afirmación independiente de exactitud clínica, financiera o jurídica.
