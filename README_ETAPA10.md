# Etapa 10 — Dashboard y estadísticas

Esta etapa agrega el módulo `estadisticas.php` y el modelo `models/Estadisticas.php`.

## Funcionalidades
- Indicadores de correos, clasificación IA, revisión y atención.
- Distribución por prioridad.
- Distribución por categoría.
- Confianza promedio y rangos de confianza.
- Concordancia actual entre prioridad IA y prioridad final humana.
- Evolución por fecha de recepción.
- Filtros por cuenta Gmail, fechas, prioridad y categoría.
- Respeto del alcance de cuentas Gmail del usuario.

## Instalación
1. Reemplazar los archivos del proyecto por esta versión.
2. Conservar el `.env` actual.
3. Conservar la carpeta `vendor/` existente. Este ZIP no la incluye.
4. No ejecutar SQL.
5. El acceso utiliza el permiso existente `ver_estadisticas`.
